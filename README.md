# 🎓 Exam Composer Pro v2.0
### Automatic Exam Paper & Worksheet Maker (Playgroup to 12th Class)

**Exam Composer Pro** ek modern, dynamic web application hai jo school/college ke computer operators aur teachers ke liye banai gayi hai. Is software ke zariye teachers apne mobile ya laptop se tests, exam papers aur solve-on-paper worksheets asani se compose kar sakte hain aur 1-click mein **world-class print-ready PDF** generate kar sakte hain.

---

## 🌟 Key Features

1. **All Classes Supported (Playgroup to 12th):**
   - Playgroup / Nursery / Prep / KG
   - Primary & Middle Classes (1 to 8)
   - Matric & Inter (9th, 10th, 11th FSc/ICS, 12th)

2. **Old English & Prestigious Calligraphy Headers:**
   - Traditional Gothic / Old English font for College & School titles.
   - Built-in Monograms (Royal Crest, Knowledge Torch, Open Book) + Custom Logo Uploader.

3. **Two Smart Paper Modes:**
   - **Mode A: Question Paper Only (Board / Academy Pattern):** Compact, zero-waste layout for separate answer sheets.
   - **Mode B: Test Worksheet (Solve-on-Paper):** Automatic answer writing lines under questions:
     - 4-Lines English handwriting ruling for junior classes.
     - Urdu 2-Lines ruling.
     - Dotted lines for primary classes.
     - Standard single lines.
     - Empty boxes for diagrams and rough working.

4. **Page-Saving & Minimum $\ge$ 12pt Font Guarantee:**
   - Font size is locked to $\ge$ 12pt so print and photocopy are 100% crisp and readable.
   - **"⚡ Auto-Fit to 1 Page"** feature to eliminate wasteful 1.25 page overflow.
   - **2-Column Layout** toggle to save 50% paper and photocopying cost.

5. **Arabic & Math Equation Assistant:**
   - Arabic & Islamiyat: Authentic Amiri Quranic font with a 1-click **Harakat / Airaab Toolbar** (َ ِ ُ ً ٍ ٌ ّ ْ ٰ ٓ ﴿ ﴾).
   - Mathematics: KaTeX vector rendering for fractions ($\frac{a}{b}$), roots ($\sqrt{x}$), quadratic equations, and matrices ($\begin{bmatrix} a & b \\ c & d \end{bmatrix}$).

6. **Smart Teacher Inputs:**
   - 🎙️ **Voice Typing:** Speak in English or Urdu directly to type questions.
   - 📷 **OCR / Photo Scanner:** Upload a photo of a book page to extract text automatically.
   - 📋 **Bulk Paste / WhatsApp Import:** Paste numbered list of questions to convert in 1 second.
   - 🔑 **Teacher Answer Key Generator:** Generates a solved MCQ key for fast paper checking.
   - 🔀 **Paper Codes Shuffler (Code A, B, C, D):** Prevents cheating during exams.

## 🖨️ How to Print or Save as PDF
1. Click the **"Print / Save PDF"** button on the top right.
2. In the browser print dialog:
   - **Destination:** Select your physical printer OR choose **"Save as PDF"**.
   - **Paper Size:** A4.
   - **Margins:** Default or None.
   - **Options:** Make sure *"Background graphics"* is checked.
3. Click **Print** or **Save**!
